# ビルドと動作検証の手順

開発は **WSL (Ubuntu)** で行い、`x86_64-pc-windows-gnu` 向けにクロスビルドします。できた `lvt.exe` を **Windows** で実行して確認します。

## 1. 初回セットアップ (WSL)

```bash
# Rust (未導入の場合)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Windows 向けターゲットとリンカ (mingw-w64)
rustup target add x86_64-pc-windows-gnu
sudo apt update && sudo apt install -y mingw-w64
```

## 2. ビルド

```bash
cd ~/work/lvt-editor-c

# OS 非依存部のテスト (Linux 上で実行される)
cargo test -p lvt-core

# Windows 向けの静的チェック
cargo clippy --workspace --all-targets --target x86_64-pc-windows-gnu

# Windows 向けビルド
cargo build-win            # デバッグ版:   target/x86_64-pc-windows-gnu/debug/lvt.exe
cargo build-win-release    # リリース版:   target/x86_64-pc-windows-gnu/release/lvt.exe
```

`build-win` と `build-win-release` は `.cargo/config.toml` で定義したエイリアスです。
`+crt-static` を指定しているので、生成される exe は MinGW のランタイム DLL に依存しません。
デバッグ版はコンソールウィンドウ付きで起動し、パニック時のメッセージを確認できます。リリース版は GUI のみで起動します。

## 3. Windows で実行

次のどちらかの方法で実行します。

**A. WSL から直接起動 (手軽)**
```bash
./target/x86_64-pc-windows-gnu/release/lvt.exe
./target/x86_64-pc-windows-gnu/release/lvt.exe /mnt/c/Users/<名前>/Desktop/test.txt   # ファイルを指定
```
WSL interop により、Windows のプロセスとして起動します。引数のパスは Windows から見えるパスである必要があります (`/mnt/c/...` は自動変換されないので、`$(wslpath -w path)` を使ってください)。

**B. Windows 側にコピーして起動 (推奨: 実際の利用に近い)**
```bash
scripts/deploy.sh                 # リリースビルドして %USERPROFILE%\lvt\lvt.exe にコピー
scripts/deploy.sh /mnt/c/tools    # コピー先を指定する場合
```
コピー後は、エクスプローラーでダブルクリックするか、ファイルを `lvt.exe` にドラッグ&ドロップして起動します。

> WSL のファイルシステム (`\\wsl$\...`) 上の exe を直接実行すると、遅くなったりセキュリティ警告が出たりすることがあります。B の方法を推奨します。

## 4. テストデータの生成

```bash
python3 scripts/gen_testdata.py /mnt/c/Users/<名前>/lvt/testdata 300   # 300MB の大容量ファイルを含む
```

生成されるファイル:

| ファイル | 内容 |
|---|---|
| `utf8_crlf.txt` / `utf8_lf.txt` / `utf8_bom.txt` | UTF-8 の各形式 |
| `sjis.txt` / `eucjp.txt` | Shift_JIS、EUC-JP (BOM なし。自動判定の確認用) |
| `utf16le.txt` / `utf16be.txt` | UTF-16 (BOM 付き) |
| `emoji_surrogate.txt` | 絵文字・サロゲートペア (𠮷) |
| `long_line.txt` | 100 万文字の 1 行 |
| `sample.md` | Markdown のハイライト確認用 |
| `large_300mb.txt` | 大容量ファイル (約 300 万行) |

読み込み性能を WSL 上で単体で測ることもできます: `cargo run -p lvt-core --release --example load_bench -- <file> [検索語]`

## 5. 動作検証チェックリスト

各項目を確認し、問題があれば「手順・期待した結果・実際の結果」をお知らせください。

### 起動・ウィンドウ
- [ ] `lvt.exe` をダブルクリックすると「無題」のタブ 1 つで起動する
- [ ] ウィンドウのサイズ変更・最大化で表示が崩れない
- [ ] 高 DPI (拡大率 150% など) で文字がぼやけない。拡大率の異なるモニタ間で移動したときに表示が追随する
- [ ] タスクマネージャーで、起動直後のメモリ (ワーキングセット) が十数MB 程度である

### 入力・編集
- [ ] 英数字の入力、Enter (前の行のインデントを引き継ぐ)、Tab、Backspace、Delete
- [ ] **日本語入力 (IME)**: 変換中の文字列がキャレット位置に表示され、確定した文字列が挿入される
  - 行の途中で変換すると、後ろの文字が右へ押し出される (重なって表示されない)。変換中の文節は背景色で示され、候補ウィンドウが入力中の行を隠さない
- [ ] 絵文字 (Win+. で入力) やサロゲートペアの文字が 1 文字として扱われる (←→ で 1 回で移動する)
- [ ] 矢印キー、Home (インデントの後ろ ↔ 行頭)、End、PgUp/PgDn、Ctrl+Home/End
- [ ] Ctrl+←→ で単語移動する (日本語は ひらがな / カタカナ / 漢字 / 英数 の区切りで止まる)
- [ ] Shift+移動で選択できる。複数行を選択して Tab / Shift+Tab でまとめてインデント・インデント解除できる
- [ ] 上下移動で桁位置が保たれる (全角文字を含む行同士でも、短い行をまたいでも)
- [ ] Ctrl+Z / Ctrl+Y (Ctrl+Shift+Z): 連続して入力した文字がまとめて取り消される
- [ ] Ctrl+X / C / V: 他のアプリ (メモ帳など) とのコピー・貼り付けで改行が正しく扱われる
- [ ] Ctrl+A で全選択、Ctrl+D で行 (または選択範囲) を複製する
- [ ] Ctrl+Backspace / Ctrl+Delete で単語単位に削除する

### マウス
- [ ] クリックでキャレットが移動し、ドラッグで選択できる。ドラッグ中にウィンドウの上下外へ出ると自動でスクロールする
- [ ] ダブルクリックで単語を選択する
- [ ] 行番号をクリック・ドラッグすると行単位で選択する
- [ ] ホイールで縦スクロール、Shift+ホイールで横スクロール、Ctrl+ホイールで文字サイズを変更する
  - 全行が画面に収まっているときは横スクロールしない。長い行があるときも、最長行の末尾 (と少しの余白) より右へはスクロールしない
- [ ] メッセージボックス (未保存の確認など) とファイルダイアログのボタンが、角の丸い現行の Windows の見た目で表示される (マニフェストが埋め込まれている)
- [ ] スクロールバーのドラッグ・クリックが機能する

### ファイル
- [ ] Ctrl+O で開く (複数選択可)。ドラッグ&ドロップでも開ける
- [ ] 各文字コードのテストファイルが文字化けせずに開き、ステータスバーの文字コードと改行コードが正しい
- [ ] 編集して Ctrl+S で保存し、元の文字コード・改行コード・BOM の有無が保たれる (別のエディタやバイナリで確認)
- [ ] 「文字コード」メニュー → 保存時の文字コード / 改行コードを変更して保存すると、変換される
- [ ] Shift_JIS のファイルに絵文字を入れて保存すると、UTF-8 で保存するか確認される
- [ ] 「指定した文字コードで開き直す」で文字化けを直せる
- [ ] 未保存のタブを閉じる、またはウィンドウを閉じると、保存するか確認される (はい / いいえ / キャンセル)
- [ ] 同じファイルを再度開くと、既存のタブに切り替わる

### タブ
- [ ] Ctrl+N で新しいタブ、Ctrl+W で閉じる、Ctrl+Tab / Ctrl+Shift+Tab で切り替え
- [ ] タブのクリックで切り替え、× または中クリックで閉じる
- [ ] 変更のあるタブには ● が付き、ウィンドウタイトルに * が付く
- [ ] タブが多数あると、タブの幅が縮んで収まる
- [ ] タブをドラッグして左右に並べ替えられる。ドラッグ中のタブはアクティブのまま、隣のタブの中央を越えたところで入れ替わる
- [ ] タブをクリックしただけ (動かさない) では並べ替わらない。× の上から始めたドラッグでは並べ替えず、タブを閉じる
- [ ] Ctrl+Shift+PgUp / Ctrl+Shift+PgDn でアクティブなタブを左右に移動できる

### 検索・置換・移動
- [ ] Ctrl+F で下部に検索欄が開き、入力に合わせて一致箇所へ移動して強調表示される
- [ ] Enter / F3 で次へ、Shift+Enter / Shift+F3 で前へ。末尾まで行くと先頭に戻り、ステータスバーに表示が出る
- [ ] Alt+C で大文字・小文字の区別、Alt+R で正規表現を切り替えられる
- [ ] Ctrl+H: 検索文字列 → Enter → 置換後の文字列 → Enter ですべて置換される。正規表現なら `$1` が使える。Ctrl+Z で一括して元に戻せる
- [ ] Ctrl+G で行番号 (`123` または `123:5`) を入力すると、その位置へ移動する
- [ ] Esc で検索欄を閉じ、もう一度 Esc で強調表示を消す

### 大容量ファイル (large_300mb.txt)
- [ ] 開くまでの時間 (ステータスバーに秒数が表示される) が数秒以内である
- [ ] 開いた後のメモリがファイルサイズの 1.2 倍程度である (タスクマネージャー)
- [ ] Ctrl+End で末尾へ瞬時に移動する。スクロールバーのドラッグが滑らかである
- [ ] 末尾付近の編集・Undo が遅延なく反応する
- [ ] 検索 (例: `002999999`) が数秒以内に終わる
- [ ] 保存にかかる時間が妥当である

### 表示
- [ ] `long_line.txt` を開いても固まらない (表示は先頭 20,000 文字まで)
- [ ] `sample.md` で見出し・強調・コード・リンク・引用・リストが色分けされる。コードブロック内の `#` が見出し扱いされない
- [ ] 表示メニュー → ダークテーマで配色が切り替わる
- [ ] Ctrl+= / Ctrl+- / Ctrl+0 で文字サイズを変更・リセットできる (JIS キーボードでは Ctrl+; / Ctrl+-)

### URL の自動リンク
- [ ] `https://example.com`、`http://…`、`www.example.com` が、どの種類のファイルでもリンク色と下線で表示される
- [ ] `詳しくはhttps://example.com/docを参照。` で、URL 部分だけ (「を参照。」を含まない) がリンクになる。`(https://example.com)` の閉じ括弧、文末の `.` も含まない
- [ ] Ctrl を押しながらリンクの上にマウスを置くと手の形のカーソルになる (マウスを動かさずに Ctrl を押しても切り替わる)
- [ ] Ctrl+クリックで既定のブラウザが開く。`www.` で始まるものは https で開く。Ctrl なしのクリックでは通常どおりキャレットが移動する

### 詳細 (`*[…]`) の折りたたみと詳細パネル
`memo.lvt` と `memo.txt` に、たとえば次の行を書いて確認します: `*[牛乳\n卵\n\]パン\] 2 個] 買い物`
- [ ] 本文では行頭が 📝 1 文字になり、`買い物` はそのまま表示される。先頭に空白やタブがあっても折りたたまれる
- [ ] キャレットをその行に置くと、本文の右上に詳細パネルが出て、「牛乳 / 卵 / ]パン] 2 個」が改行されて表示される。キャレットが別の行に移るとパネルは消える
- [ ] キャレットがパネルの位置の行にあると、パネルが右下に移る
- [ ] ←→ (Vim では h / l) で 📝 を 1 文字として飛び越え、内側にキャレットが入らない。マウスでクリックしても内側に入らない
- [ ] 📝 の直後で BS、直前で Del (Vim では `x`) を押すと、詳細全体が消える。Undo で戻る
- [ ] F2、📝 のダブルクリック、パネルのクリックで編集ウィンドウが開く。日本語入力・改行・コピーと貼り付けができる。Ctrl+Enter (または OK) で確定すると内容が更新され、1 回の Undo で戻る。Esc でキャンセルすると何も変わらない
- [ ] 詳細のない行で F2 を押して内容を入力・確定すると、行頭に `*[…]` が作られる
- [ ] 上下移動で、📝 のある行とない行の間でも桁位置が保たれる
- [ ] 表示メニュー → 「.txt で詳細ビューを使う」をオフにすると、.txt では `*[…]` がそのまま表示される。.lvt は折りたたまれたまま。再起動しても設定が保たれる
- [ ] .md など他の拡張子では折りたたまれない。無題のタブを .lvt で保存すると折りたたまれる
- [ ] 300MB のテキストファイル (.txt) で、スクロール・編集・全置換の速度が変わらない

### Vim キーバインド
**既定でオン** です。表示メニュー → 「Vim キーバインド」(または Ctrl+Alt+V) で切り替えます。
- [ ] 初回起動 (`%APPDATA%\lvt\settings.toml` がない状態) で Vim キーバインドがオンになっている
- [ ] オンにするとステータスバーに `NORMAL` が出て、キャレットがブロックになる。オフにすると元に戻る。メニューのチェックが連動する
- [ ] `:` `/` `?` を押すと、本文の下に入力欄が開くのではなく、ステータスバーの左端 (行・桁の表示の位置) に `:` などと入力文字列・キャレットが表示される。Enter / Esc で行・桁の表示に戻る。日本語 (IME) の入力位置もそこに合う
- [ ] **lvt を再起動しても、オン/オフが保たれる** (`%APPDATA%\lvt\settings.toml` が作られる)
- [ ] 移動: `h j k l` `w b e` `W B E` `0 ^ $` `gg G 10G` `f t F T ; ,` `%` `{ }` `H M L` `Ctrl+D/U/F/B`、矢印キー。回数 (`3j` など)
- [ ] 日本語の文章で `w` / `b` が ひらがな / カタカナ / 漢字 の境界で止まる
- [ ] 入力途中のキー (`2d` など) がステータスバーに表示され、キャレットが下線になる。Esc で取り消せる
- [ ] 挿入: `i a I A o O` で `INSERT` になり、Esc (または Ctrl+[) で `NORMAL` に戻ってキャレットが 1 文字左へ戻る
- [ ] **IME をオンにして挿入モードで日本語を入力し、Esc でノーマルモードに戻ると IME がオフになる** (続けて `j` を押しても変換が始まらない)
- [ ] 演算子: `dw` `cw` `yy` `dd` `cc` `D` `C` `x` `X` `s` `S` `>>` `<<` `J` `r` `~` `gUiw` `guu`
- [ ] テキストオブジェクト: `ciw` `daw` `ci"` `da(` `di{` `ci<` など
- [ ] `yy` → メモ帳に貼り付けられる (クリップボードと共有)。メモ帳でコピーした文字列を `p` で貼り付けられる
- [ ] `yy` / `dd` のあとの `p` は次の行に、`yw` のあとの `p` はカーソルの後ろに貼り付ける
- [ ] `u` で、挿入モード 1 回分 (例: `cwhello<Esc>`) がまとめて元に戻る。`Ctrl+R` でやり直す
- [ ] `.` で直前の変更を繰り返す (`ciwfoo<Esc>` → 別の単語で `.`、`dd` → `3.`)
- [ ] ビジュアル: `v` `V` で選択し、`d` `y` `c` `>` `<` `J` `~` `u` `U` `p` が使える。`o` で選択の反対側へ。`viw` などのテキストオブジェクト
- [ ] マウスでドラッグして選択するとビジュアルモードになり、そのまま `d` や `y` が使える
- [ ] 検索: `/foo` Enter で次の foo へ移り、`n` `N` で前後に移動する。`?` は逆向き。`*` `#` でカーソル位置の単語を検索する。Esc で検索前の位置に戻る
- [ ] `:w` で保存、`:q` で閉じる (未保存なら確認)、`:q!` で破棄して閉じる、`:wq` / `:x` で保存して閉じる。最後のタブで実行するとアプリが終了する
- [ ] `:42` で 42 行目へ、`:$` で最終行へ移動する
- [ ] `:s/a/b/` (現在行の最初の a)、`:%s/a/b/g` (全体)、`V` で選択してから `:` → `'<,'>s/a/b/g` (選択した行だけ)。`:%s/\(\w\+\)@/[\1]/g` のような Vim 形式のパターンと `\1` / `&` が使える。`u` で一括して戻る
- [ ] `:noh` で検索の強調表示を消す。未対応のコマンドではステータスバーにメッセージが出る
- [ ] ノーマルモードで Ctrl+S / Ctrl+O / Ctrl+W / Ctrl+Tab などの Windows のショートカットがそのまま使える。Tab キーを押してもタブ文字は入らない
- [ ] ノーマルモードのキャレットが行末の改行の上に来ない (`$` や行末でのクリックでは最後の文字の上になる)

## 6. 不具合報告のお願い

以下を添えてください。
- Windows のバージョン、ディスプレイの拡大率、IME の種類 (Microsoft IME / Google 日本語入力 など)
- 再現手順と、可能であれば対象ファイル
- デバッグ版 (`cargo build-win`) で再現した場合は、コンソールに出たメッセージ
